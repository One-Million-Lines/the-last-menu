# Contributing

Thanks for your interest in contributing.

## Local setup

```bash
npm install
npm run dev
```

## Making changes

- Use the editor and export flow to validate UI changes.
- Run `npm run build` before opening a pull request.
- Run `npm run lint` for frontend checks.

## Pull requests

1. Fork the repository
2. Create a branch for your change
3. Commit your updates
4. Open a pull request with a short explanation

## Reporting issues

Open a GitHub issue with reproduction steps, expected behavior, and screenshots when relevant.
